HOW TO ADD CASE IMAGES

1. Put your image file in this folder.
2. Open the file cover-image-links.js in the parent folder.
3. Find the matching line, for example:

   'iPhone 17 Pro Max | Silicone | Orange': '',

4. Paste the image path between the quotes:

   'iPhone 17 Pro Max | Silicone | Orange': 'images/17pm-silicone-orange.jpg',

You can paste an HTTPS image link instead. Each line is a separate case, so Silicone, TechWoven, Clear and every other material can have its own image.
